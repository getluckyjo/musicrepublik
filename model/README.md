# MerchMe scenario model

Month-by-month 36-month model behind the feasibility report in `reports/`.

- `merchme_model.py` – model engine (unit economics, scenarios, P&L)
- `model2.py` – editable assumptions; run it to print all scenarios, sensitivities and break-even volumes
- `report_tables.py`, `sens.py` – helpers that produced the report tables

Run: `cd model && python3 model2.py`
